# Gestao-de-Obras
ObraMaster é um sistema de gestão para empresas de construção e reforma, que centraliza todo o ciclo de uma obra — do orçamento inicial ao agendamento, execução, pagamento e conclusão — substituindo controles manuais (planilhas, WhatsApp) por uma plataforma única, com o cliente sendo informado automaticamente sobre o andamento do serviço.
